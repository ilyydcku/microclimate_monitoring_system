# Роли и предварительная матрица доступа

## 1. Роли пользователей

| Роль | Назначение |
|---|---|
| Оператор | Просматривает текущие и исторические показания, выполняет поиск и фильтрацию данных, формирует отчеты |
| Инженер | Анализирует показания, контролирует корректность данных и источников, изменяет состояние записей в пределах полномочий |
| Администратор | Управляет учетными записями и ролями, контролирует журнал событий и административные настройки |

Роли не наследуют друг друга автоматически. Если одному пользователю требуется совмещение ролей, это должно быть определено отдельно.

Действия, которые явно не разрешены матрицей, считаются запрещенными.

Неаутентифицированному пользователю доступ к прикладным данным, административным операциям и журналу событий не предоставляется.

## 2. Предварительная матрица доступа

| Операция | Оператор | Инженер | Администратор |
|---|---|---|---|
| Просмотр текущих показаний | Разрешено | Разрешено | Не предоставлено этой ролью |
| Просмотр истории измерений | Разрешено | Разрешено | Не предоставлено этой ролью |
| Поиск и фильтрация данных | Разрешено | Разрешено | Не предоставлено этой ролью |
| Формирование отчетов | Разрешено | Разрешено | Не предоставлено этой ролью |
| Изменение состояния записи | Запрещено | Разрешено для доступных записей | Запрещено |
| Проверка сведений об источнике измерений | Только просмотр сведений, необходимых для отображения показаний | Разрешено | Только служебные сведения, необходимые для администрирования |
| Управление учетными записями и ролями | Запрещено | Запрещено | Разрешено |
| Просмотр журнала событий безопасности | Запрещено | Запрещено | Разрешено |
| Изменение конфигурации приложения | Запрещено | Запрещено | Разрешено только в пределах административных полномочий |

## 3. Ограничения доступа

1. Оператор не может изменять показания, сведения об источниках, роли пользователей или конфигурацию.
2. Инженер может изменять только те состояния записей, для которых ему предоставлены соответствующие полномочия.
3. Администратор не получает автоматически доступ ко всем прикладным данным только на основании административной роли.
4. Доступ к журналу событий предоставляется только административной роли.
5. Доступ к секретным параметрам приложения не предоставляется через пользовательские функции системы.
6. Проверка полномочий и механизмы авторизации относятся к будущей реализации. В версии v0.2 они только зафиксированы как требования.
